# NOPE 1.0.0

Android 9+、ARM64 离线输入法，支持中文全拼、日本語罗马字、English 与 Code。包名保持 `app.msime.offline`。

- 默认点按语言键在中文与 English 间快速切换；设置 → 输入语言 → 调整快速切换语言，可选择两种或更多键盘。长按空格仍可选择全部键盘。
- Code 控制行的 Tab 移到最左侧；数字面板的 Tab 同样放到左列首位。保留标准 Tab 按键事件、终端补全、缩进和全部原有运算符。
- 新增「淡紫像素」皮肤：淡紫毛玻璃材质、粉紫边缘光、电光蓝细边框、灰白窗口面板、像素字形与页脚爱心。使用原生 Drawable 及统一装饰分层，不把概念图当作键盘背景，不改变键位、按键尺寸或触摸区域。
- 保留 S4U 与其他皮肤、方正 N/ope 标志、按压反馈、气泡、22sp 候选、展开滚动候选和自适应长剪贴板预览。只有 S4U 使用唱片标志。
- 保留完整原生引擎启动资源、日文词库、原版源码与许可证；不再移除引擎要求的资源。

本版沿用本机原开发签名，可覆盖相同签名旧版。只申请震动权限，没有应用运行时网络功能。

本地 Java / Python 回归、Android 构建、Lint、APK 原始资源 / 签名与完整源码包均有核验报告。最终 Android 字体、淡紫材质、触摸及 Termux 操作仍待手机重连验收；预览图是设计稿，不是运行截图。
