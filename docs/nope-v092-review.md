# NOPE0.9.2：S4U背景斜度与LCD快捷栏

上一版错误地把S4U整体SkinStack设置为7度rotationX，导致键盘、候选文字和触摸映射一起变形。用户明确要求斜度仅属于背景、键盘保持原标准尺寸。本版移除服务内整层变换，只对SkinStack的独立background View施加透视；frame装饰跟随同一背景矩阵，其余区域装饰保持平面。SkinStack、内容布局、按键尺寸、候选高度与触摸区域沿用KeyboardMetrics。JSON透视target仅接受background，旧v1未指定target的配置也只投影背景。

S4U空闲快捷栏恢复剪贴板、表情、设置三项，浅绿图标置于墨绿色LCD面板，唱片入口与收起箭头仍在左右。开始组字后同一区域显示输入串和候选，右侧箭头继续展开候选；工具/表情/剪贴板面板行为保留。

按用户确认，NOPE保留N在上、ope在下的结构，去掉圆弧字腔和圆端，采用等宽直线、直角字腔；键盘标志与应用矢量图标一致。只有S4U继续使用唱片入口。

本地回归检查全部皮肤配置的background目标与真实字体轮廓；真机回归新增背景投影而内容矩阵为identity、按键尺寸不变的断言，供手机重新连接时执行。编译/Lint、APK权限/完整原生资源/皮肤字体/签名、源码包摘要分别核验。本次没有重新连接手机，不将本版静态示意或编译结果宣称为真机视觉验收。历史中日文引擎真机通过记录仍保留，引擎和词库本版未更改。
