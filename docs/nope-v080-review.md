# NOPE 0.8.0：日文输入与N/ope标志

日文模式复用原生引擎的japanese方案，包名、JNI、开发证书和已有本机数据目录保持兼容。新增资源来自原生0.3.1源码固定的resources/components/japanese.lock.json：msime-japanese.dat（66,547,565字节），以及Mozc许可证与字典来源说明；每项核对大小和SHA256。应用仍仅请求VIBRATE，词典随APK离线安装，不在手机上下载。

输入流程：长按空格选择日本語，或点按中/日/EN切换；系统输入法subtype及设置页也提供日文入口。罗马字在引擎保留，编辑器组字显示reading；nihon显示にほん。首次空格104定位首项，后续空格102切换候选，回车1确认；没有转换时回车11提交假名，避免把nihon原文提交。只有兜底候选时空格按读音结束。编辑改变、选词结束和会话关闭清除转换状态；转换期间删除先退出转换，继续键入先确认当前候选。候选使用原生highlighted字段显示强调色，展开后的任意候选沿用会话与generation校验。长音和拨音分隔可在符号页输入-及'，仍走罗马字引擎。中文繁简转换显式限制在中文模式。

资源安装标记同时包含中文和日文清单，升级时重新校验；不会因旧版词库标记存在而漏装日文。准备期间共用会话输入缓存，快速输入和硬件键盘均可暂存。切换模式、标点和工具入口按日文当前读音/转换状态结束组字。

标志改为上排N、下排ope，工具栏和应用图标都使用路径绘制。没有增加动画，保留原有皮肤、即时反馈、候选字号和按键字号设置。

验证：纯逻辑回归覆盖日文空格、回车、兜底、取消、编辑变化、会话重置及假名组字显示；资源测试逐字节比对固定清单、模型摘要和许可证。Android编译/Lint、APK权限/原始资产/日文资源/系统入口/JNI/签名/16KB对齐，以及源码包完整性分别检查。静态皮肤预览仅用于标志构成参考，不能替代Android运行。当前ADB受设备目录权限限制，未完成真机/模拟器验收；需要在手机上测试nihon、konnichiha、ko-hi-、连续转换与首字母、候选展开、切换语言、私密字段、横屏及大字体。
