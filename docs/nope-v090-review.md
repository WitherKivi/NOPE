# NOPE 0.9.0：S4U、反馈与长剪贴板

S4U是设置页和键盘皮肤面板中的实际名称，运行ID为retro。它用原生Canvas实现米色机壳、机械台阶键帽、抖色边缘、自绘5×7拉丁字和灰绿LCD候选；中文/日文候选仍用系统字体。没有把整张效果图当背景，也没有加入位图和字体包。中文、日文罗马字、英文、Code共用此材质并保留各自键位。CD唱片机图标只在S4U键盘内使用，其他皮肤和应用图标保留N/ope。

所有皮肤候选由17sp提升到22sp，横栏和展开区不按词长缩字，系统字体设置仍生效。默认浅色key变为#f9f1f5、special变为#f0cbdc；深色special改#48323f、outline改#655060。其余皮肤保持原材质。

按压在DOWN时即时生效，普通皮肤下移1dp/缩放.97，S4U下移2dp不缩放，松开100ms复位；可打断并遵守系统动画开关。气泡使用非触摸PopupWindow，按键不等待动画上屏，字母和数字可预览；快速连按用所有者与generation避免旧隐藏任务清除新气泡。滑动变体、离开页面、会话重建、私密字段清除气泡。设置独立控制按压、气泡、震动。

剪贴板问题源于KeyButton按整段文本宽度拟合，两行长文本会被缩得过小。现在原生autosize优先，卡片12–15sp、顶部12–16sp，最多两行且尾部省略；预览压平换行、限制384个Unicode码点，避免长达65536字符参与反复排版。实际保存与粘贴仍是原始全文。卡片最低高度为max(76dp,12sp×2.8+20dp)，随系统大字体增加。禁用单个ASCII卡片的像素字体及大写转换。回归覆盖长中英日文、URL、换行、emoji代理对、大小写、最小字号和大字体高度。

运行资源清单从原版desktop-dictionary.lock.json派生，省略msime-wubi.db（14,536,704字节）和sentence-model.safetensors（4,486,280字节），共19,022,984字节。NOPE没有五笔入口；固定上游generation.rs的merge_split_wubi允许缺失。神经重排默认及宿主显式关闭，普通拼音/英文/n-gram保留。来源原始摘要和完整上游源码仍在，runtime清单与APK核验显式列出省略项。安装时只删除resources-v031内两个明确文件及.part，绝不遍历local-state、学习或剪贴板。引擎JNI未改动。

验证包括：纯Java/Python逻辑回归，S4U及所有皮肤文字对比度，快速气泡所有权/边缘/隐私，明确文件清理边界，长剪贴板Unicode预览；Android assembleDebug及lintDebug；最终APK权限、原始资产、日文模型/许可、JNI符号、签名与16KB对齐；源码ZIP文件集合与逐文件摘要。最终计数与交付摘要见dist中的0.9.0-delivery.json。
