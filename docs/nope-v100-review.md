# NOPE 1.0.0 实现与验证范围

版本提升为 1.0.0，Android versionCode 12，仍使用开发签名构建。没有重新编译或替换水杉 0.3.1 原生 JNI。

语言键使用 QuickLanguages 读取 `quick_languages` 配置，默认 CHINESE,ENGLISH。设置中可勾选中文、English、日本語、Code，至少两项，按列表顺序循环。当前模式不在快速列表时，下一次点击进入列表首项；长按空格不受快速列表限制。无效或旧配置安全退回中英互切。切换仍经过现有 changeMode，保留组字确认、暂存上屏与密码字段英文限制。

Code 控制行只调整添加顺序，Tab 最左，接着片段类型、Esc、Ctrl、Alt，权重与高度保持原值。数字面板的 Tab 与除号互换位置，左列四项、右列三项及各列宽度保持原值，所有数字与运算符保留。Tab 继续经 stroke / CodingInput 发送 KEYCODE_TAB 的 down/up，不改写为若干空格。

新增 lavender 皮肤（界面名称：淡紫像素），使用 PixelGlassDrawable 绘制静态扩散色、像素高光、蓝紫边框、粉紫边缘光。候选与快捷栏沿用标准高度的窗口面板，不额外插入概念图标题栏。原生材质渐变模拟毛玻璃，不采样宿主画面。轻微颗粒在 z5，页脚像素心形在 z30，不拦截触摸。所有语言复用同一套标准键位，透视为 0，N/ope 标志保持原结构。像素字形复用现有自制 TTF，没有新增大图到 assets；概念图保存在 docs/design。

纯逻辑回归新增快速切换的默认行为、自定义循环、不在列表的当前模式及无效配置测试。全部皮肤色彩对比与配置契约覆盖新皮肤。Android instrumentation 新增 lavender / S4U 的内容矩阵和标准尺寸断言，已编译，未在断开的手机执行。APK 检查保留完整 full 启动资源清单和签名，源码包逐文件核对，交付集合记录 SHA-256。

上传 GitHub 的源码保留原生库、离线资源、vendor 与全部许可证；dist、缓存和密钥从 Git 忽略。发布步骤见 github-upload.md，当前没有远程上传或自动创建仓库。
