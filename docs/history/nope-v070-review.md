# NOPE 0.7.0 修复与整理

## 快速输入

旧回声队列只保留16次写入，连续输入期间的迟到首字母或初始回报可能已被丢弃。现在保留最多256次预期；每次commit、compose、finish成功后独立登记，兼容不合并批量编辑回报的宿主。空会话focus不写finish；同步重入回报在预测更新前跳过，避免同一写入重复推进光标。收起/重开键盘不再直接使当前编辑器回声状态失效；确实失效时，在新组字前读取一次选区。

新增回归覆盖100次连续组字后再收到初始/首字母回报、分段选词的中间commit、新组字、收起后迟到finish，以及真实外部光标移动仍能取消组字。引擎尚未建立会话时缓存输入，不落入英文直输；打开引擎和手动重试后按顺序重放。失败状态仍保留输入，切换英文可提交缓存字母。

## 候选、图标和设置

右侧48dp箭头按钮展开/收起候选。展开时通过原有原生库提供的allCandidatesRaw、viewRaw、selectAnyCandidateRaw读取和选择全部候选，保留原始JNI包名；这三个符号已在原始库和最终APK中核对。全部候选查询可能更新generation，因此同步刷新横栏；点击校验编辑会话、原生会话和generation。Code建议也可展开，仍只填入文字。

展开区用原生ScrollView纵向滚动与按词长换行的CandidateFlow，不分页截断完整列表。横栏和展开区统一17sp，候选关闭键帽的自适应缩字；横栏自然宽度，展开区长文本折行。系统字体倍率生效并增加候选行高。按键文字设置80%–140%，默认100%，松开滑块保存，可恢复默认。图标和候选不随按键文字调整。

NOPE工具入口和启动图标改为横置N矢量几何图形，保持皮肤原有强调颜色。

## 文件整理

app/src按main、engine、layout、skin、features、resources分源码根目录。Java包名保持不变，避免JNI和持久数据迁移；Gradle明确注册所有目录，测试和导入脚本统一定位。删除旧版APK/源码交付、临时升级脚本、视频处理环境及视频分帧、旧日志、Python缓存、废弃IosPalette及其iOS草稿生成器。历史设计过程与0.6.0验收记录移入docs/history。未清理其他项目及父目录的个人媒体。完整上游源码、资产摘要、GPL/Unicode/OpenCC及第三方许可保留。

编译通过 `NOPE_DEBUG_KEYSTORE` 显式选择原开发证书，交付前比对0.6.0证书SHA256，避免默认用户目录变化导致无法覆盖安装。密钥不打包。

## 验证边界

纯Java/Python回归、Android debug编译及Lint、APK离线权限/原始资产/原生依赖/JNI符号/签名/16KB对齐、源码包完整性核验。Lint为0错误、23条警告，主要涉及目标API、ARM64范围、代码创建视图和中文硬编码文案。

ADB无法访问本机设备目录，未进行Android真机或模拟器运行、截图及触控验收。代码回归不能证明所有编辑器时序都已覆盖；需在手机上验证首次启动快速nihao、选词后立即输入、连续双指输入、删除后继续输入、重开键盘、展开长词滚动、所有皮肤的横屏/大字体以及Termux。
