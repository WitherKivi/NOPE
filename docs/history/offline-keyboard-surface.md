# 当前离线键面 · 0.4.0

记录日期：2026-10-09。原生 Android Views 实现，参考用户 Gboard 截图；尚无本版本真机截图。

设置页：启用 / 选择输入法、词库准备状态、普通及 Code 高度滑块与恢复默认、震动开关和强度滑块、本地学习与剪贴板记录开关、手势说明、试打与数据来源。深浅主题跟随系统。

## 键面组织

普通键盘总高是 48 dp 顶部、四行主键与 8 dp 底部。默认宽度乘 0.72，夹在 240–320 dp，自定义 220–420 dp。Code 默认加高 120 dp，独立设置 320–520 dp；控制行 40 dp、符号行 36 dp、底部导航行 44 dp，默认竖屏保持字母主键行高度。Code 高度不足 320 dp 时使用 32 / 28 / 32 dp 的紧凑附加行。普通横屏最大屏幕高度 65%，Code 最大 82%；导航栏 inset 另计。没有读取 Gboard 的实际高度。Code 闲置时隐藏 48 dp 顶栏，打字、建议或错误时展开；设置高度包含展开状态。

普通键盘顶部闲置时是工具、剪贴板、表情、设置和收起；Code 不显示这排工具；有组字、代码前缀或输入提示时显示候选。空格长按切换中文 / English / Code。工具与返回使用 24 dp 原生 compound drawable 图标，工具无中文副标题；空格留白，右侧中/英快速切换；Shift / Del / Enter 与数字入口保留明确文字标签；箭头改为原生文字，避免依赖空文本按钮的自绘。功能区不放无宿主实现的录音或翻译按钮。

字母三行 QWERTY，首排右上角数字提示；上滑选数字。部分字母有变音，括号、引号、货币及数学符号有变体。长按默认选原字符，上滑默认选第一个变体；浮窗横向拖选，货币使用三列网格，松手输入。上滑退回原位、越界、系统取消、多指中断或输入框切换不提交变体。TalkBack 长按提供可聚焦的候选按钮菜单。

两页符号分别为数字 / 常用标点和扩展符号，第三行两侧是翻页及 Del。底部有返回箭头、逗号/句号合并键、数字网格入口、留白空格、中/英和 Enter。尖括号仍可通过括号变体选择。数字面板是左侧运算符，中央 1–9，右侧百分号 / Tab / Del，底部返回、逗号、符号页、0、等号、中/英和 Enter；逗号上滑选择小数点。Code 点按符号保持半角；Unicode 是用户主动选项。

Code 顶部控制行包含 Shell 类型键、Esc、Tab、Ctrl、Alt；其下是常用半角标点。底部独立导航行依次为 Home / ← / ↓ / ↑ / → / End，主键底行使用逗号/点合并键与中/英切换，避免重复放 Home/End。长按 Shell 选择 Shell / Python / JS/TS。Ctrl/Alt 作用于下一键，片段只填入，真实终端补全使用 Tab。

Del 上滑显示清空提示，越过 52 dp 后松手执行，滑回可取消。普通输入框全选清空，Code 发送 Ctrl+U；长按 420 ms 后每 70 ms 删字。

普通字母页下滑 Z 撤回、A 全选、X 剪切、C 复制、V 粘贴；36 dp 下滑、横移不超过 27 dp，在松手时执行。滑回、多指或会话变化取消。先结束已有组字，再将撤回/选区命令交给编辑器；不自行保存输入历史。粘贴读取用户明确请求的当前纯文本，提交成功后隐藏最近复制提示。Code 不启用这些手势。TalkBack 提供同名快捷动作。

## 候选浏览与反馈

候选栏取消「更多」。页内用系统横向滚动，开始于边缘时继续向外滑 36 dp，松手请求下一 / 上一页（原生命令 100 / 101）。第一页面无上一页；竖滑、滑回、多指或会话变化不翻页。返回上一页时定位右侧，下一页定位左侧，没有新页时保留原位置。选词校验引擎 generation；剪贴板后台更新不重建正在浏览的候选栏。TalkBack 保留滚动动作。

按下即时改变背景色，无计时缩放或涟漪。KeyButton 在事件分派时统一发出震动，覆盖普通点击、候选、删除及上滑符号键；长按展开另发短反馈。设置支持开关、0–100% 强度，默认 35%，0 为关闭。支持幅度控制时用幅度和时长，不支持时用默认幅度及可调时长；效果取决于硬件和系统。VIBRATE 是唯一应用请求权限，无网络权限。

## 剪贴板

进入剪贴板后替换主键区，总高不变。两列卡片、每项两行；置顶排列在前，长按置顶 / 取消置顶 / 删除。每次加载 60 项，更多按钮继续加载；数据库不自动淘汰。当前系统复制在闲置候选行显示，避免后台数据库旧项闪回。返回剪贴板、收起键盘或成功粘贴一次会持久隐藏该次提示；历史不删，新的复制恢复提示，重开同一次复制不恢复提示。密码和私密字段不显示历史，系统敏感复制不读文本、不收录；纯文本以外不做 URI 转换。记录可关闭，多行终端粘贴先确认。

## 分类表情与玻璃材质

Unicode 17 官方 emoji-test 数据的全部 3,944 个 fully-qualified 序列随包提供，分九类，保留 ZWJ、变体选择符、肤色和旗帜组合。加载与系统字体支持检查在后台完成；不支持的序列隐藏，显示范围取决于系统字体。GridView 复用屏内按钮，分类栏横向滚动；点击表情只提交该序列，保留面板与滚动位置。Unicode 许可随 APK，源码包包含原始数据和生成脚本。

键盘与设置页在 Android 12+ 使用 system_accent1 / system_neutral 调色板，旧版采用蓝灰色；明暗变化重建键面。根层为柔和渐变、顶部 22 dp 圆角，按键为微透材质及轻边线。窗口模糊监听系统可用状态：只有 decor 范围不超过键盘时启用 64 px 背景模糊；全屏 IME 窗口、系统禁用和旧版本使用不透明渐变，不截取宿主屏幕，不模糊文字，不影响上方应用。真实模糊效果仍需 ROM 验证。

## 设备验收

需核验中文词库首次准备、组字与候选、切换与收起重开；Termux 和 SSH 的 Tab / Ctrl-C / Ctrl-U / 方向 / Home-End；两页符号和数字面板，边缘浮窗、货币网格、上滑与滑回取消、快速连按、边缘候选翻页与滑回；震动强度及关闭；剪贴板跨应用复制、敏感标记、置顶重启保留和多行粘贴；明暗主题、小屏、横屏、导航栏、大字体与 TalkBack。当前尚无设备运行结果。
