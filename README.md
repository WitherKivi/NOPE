# NOPE 输入法

- 一款完全不需要任何权限的安全输入法，目前支持中文，英文，日本罗马音
- 特色coding键盘支持智能提示补全，长按空格切换键盘
- 基于水杉引擎

## 输入与候选

- 点按语言键默认中文 ↔ English；设置可选择两种或更多快速切换键盘。长按空格始终可选择全部模式。
- 中文全拼、分段选词与本机学习；可切换繁体输出。日文罗马字输入后，空格转换、回车确认。
- 候选保持统一字号，横向浏览，右侧箭头展开可上下滚动的列表。展开结果缓存，按钮按可见行创建。
- 上滑字母输入数字，长按或上滑选择符号变体；下滑 Z/A/X/C/V 撤回、全选、剪切、复制、粘贴。
- Code 保留终端控制键，Tab 在最左侧，用于补全或缩进。代码片段只填入文字，不自动执行。

## 皮肤与反馈

- 所有语言共用标准键位与触摸布局。设置可调整键盘/Code 高度、按键文字大小、动效、气泡和震动。
- 皮肤 JSON 支持色板、区域、上下装饰层及背景透视导入，可随时恢复默认。

## 剪贴板与表情

- 剪贴板历史仅保存在本机，支持 📌 置顶、删除和保留时间；置顶条目不自动过期。
- 长文本预览自动适配两行，点击粘贴完整原文。
- 分类表情和常用表情，按设备字体过滤不可显示的序列。

## 设置与安装

设置页面跟随系统：日间乳白雾面，夜间灰色雾面，带轻微纹理和圆角功能按钮。

从 [GitHub Releases](https://github.com/WitherKivi/NOPE/releases) 下载 APK；安装后打开 NOPE，依次选择「启用输入法」「选择输入法」。词库随包提供，无需另行下载。当前 APK 沿用开发签名，可覆盖相同签名旧版并保留本机设置和记录。最终界面与操作效果需要在手机上验收。

只申请震动权限，没有联网、录音或联系人权限。私密字段不学习、不展示剪贴板。源码保留原引擎、完整离线资源、上游源码及许可证；不要因界面未开放就删除原生启动要求的词库或模型。
